# CatWorld — практическая №3 (MVVM)

Это версия **исходного проекта `proect(2).zip`** по методичке «Практическая работа №3», посвящённой MVVM. Это **не** практическая про Intent/Navigation Drawer.

## Что изменилось

- `app/.../MainActivity.java` — теперь экран только обрабатывает нажатия и наблюдает за LiveData. Он больше не вызывает UseCase напрямую.
- `app/.../MainViewModel.java` — вся логика кнопок, вызовы UseCase, `MutableLiveData`, `MediatorLiveData` и фоновое выполнение Room-запросов.
- `app/.../MainViewModelFactory.java` — собирает репозитории и передаёт их ViewModel; сама ViewModel не хранит Android Context.
- `app/src/main/res/layout/activity_main.xml` — добавлена кнопка «Показать данные сети и БД» и поле сводки.
- `app/build.gradle.kts` — добавлены зависимости ViewModel и LiveData.
- `data/.../RoomCatStorage.java` — удалено небезопасное `allowMainThreadQueries()`: обращения из новой ViewModel выполняются в фоне.

## Как проверять

1. Откройте эту папку как проект в Android Studio, дождитесь Gradle Sync.
2. Запустите `app`. Авторизация и гостевой режим работают как в исходном проекте.
3. Нажмите «Показать породы кошек» — результат придёт через LiveData.
4. Нажмите «Показать данные сети и БД» — получите сводку `MockNetworkApi` и Room через `MediatorLiveData`.
5. Добавьте Бенгальскую кошку в избранное и снова проверьте сводку: количество избранных должно увеличиться.
6. Поверните устройство: текущий текст результата сохранится, потому что ViewModel не пересоздаётся при обычном повороте.
7. По желанию откройте Logcat и ищите `CatWorldMVVM`: строки `MainViewModel created` / `MainViewModel cleared` показывают жизненный цикл.

## Особенности текущего проекта

- `MockNetworkApi` **имитирует** внешний сервис; реальный HTTP-запрос не реализован.
- Распознавание кошки пока **заглушка**, а не обученная TFLite-модель.
- Оригинальный интерфейс не содержал изображений кошек. Эта версия фокусируется на требованиях раздела «MVVM / LiveData / MediatorLiveData», без добавления недостающих функций из общих требований предыдущих практик.
- Автоматически собрать APK здесь не удалось, поскольку в текущей среде нет Android SDK/настроенной сборки Gradle. Проверить сборку и запуск нужно в Android Studio.

## Принцип работы простыми словами

`MainActivity → MainViewModel → UseCase → Repository → MockNetworkApi / Room`

Потом результат возвращается `LiveData → MainActivity`, а `MediatorLiveData` объединяет результаты двух разных источников и показывает их в отдельном поле.
