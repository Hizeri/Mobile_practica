ПРАКТИЧЕСКАЯ РАБОТА №5 — RETROFIT И PICASSO

Это отдельный проект Android Studio, созданный из присланного проекта Praktika5.
В нём один модуль: app. Старых модулей практической №4 нет.

ЧТО СДЕЛАНО
1. Retrofit + Gson: GET /todos с https://jsonplaceholder.typicode.com/.
2. Todo.java — модель задачи; ApiService.java — описание запросов.
3. RecyclerView + TodoAdapter + TodoViewHolder: список из 200 задач.
4. CheckBox + PATCH /todos/{id}: отправка обновления completed.
5. Picasso: фотографии с https://picsum.photos/ (иллюстративные, т.к. Todo не содержит URL фото).
6. Switch: переключение centerCrop / centerInside.
7. Обработка ошибок сервера, DNS, сети и загрузки картинок.

КАК ЗАПУСТИТЬ
1. Распакуйте архив.
2. Android Studio -> File -> Open -> папка Praktika5_RetrofitApp.
3. Дождитесь Gradle Sync и скачивания зависимостей.
4. Выберите конфигурацию app и эмулятор, нажмите Run.
5. Нужен интернет в эмуляторе.

ПРОВЕРКА
- Должно быть: «Получено задач из сети: 200».
- Кнопка «ОБНОВИТЬ СПИСОК» повторно запрашивает данные.
- CheckBox отправляет PATCH; при ошибке состояние откатывается.
- Переключатель меняет обрезку изображений.

ВАЖНО: JSONPlaceholder — учебный сервис. PATCH возвращает ответ, но
не сохраняет изменения постоянно. После обновления списка они сбросятся.
Фото берутся из отдельного публичного сервиса Picsum Photos и могут
временно не загружаться при сетевых ограничениях; есть заглушка.

ПРИМЕЧАНИЕ: исходники проверены статически, но Android-сборка
в этой среде не запускалась (нет Android SDK). Проверьте в Android Studio.
